# 当日ドロワー見出し: 役割と強弱を分ける

**不採用の変更記録。** ユーザーから、まとめるのはプリセット2つであり、＋の強調方法と位置も逆効果とのフィードバックを受けた。動作確認の成功をデザインの承認として扱わない。続く修正は [プリセットと＋の分離](../preset-pair-right-add/README.md) を参照。

2026-09-28。初回実装に対する「4つのボタンが並列で、個別に解釈する負担がある」という指摘への修正。

1. 当日ドロワーの見出しを確認。変更前は予定プリセット・一日プリセット・＋・時間軸が同じ色、大きさ、間隔だった。入口は近いが、表示を変える操作と予定を追加する操作の関係を見た目から区別できなかった。
2. 日付と時間軸を隣接させ、表示操作を左にまとめた。＋と2つのプリセットには共通の薄い背景を付け、＋だけを塗りつぶして強調。閉じる操作は右端に離した。各機能へ直接入れる手数と44ptの操作領域は維持。
3. 通常サイズでは一行、文字拡大時には表示操作と追加操作を上下に分ける。シミュレータと実機Releaseで、表示・入口・詳細の高さ・余白から戻る・2種類のプリセット適用を各6件確認し成功。
