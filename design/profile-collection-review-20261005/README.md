Ryuの指摘により、初期装備の色差と、生成装飾のモチーフ・世界観の不一致を混同していた評価を訂正する。主な懸念は、Appleの標準的なパーツと近い初期描画の色ではなく、蝋燭や石などの生成意匠がLiminalogの世界から離れて見えること。下の初期プロフィール画像だけでは、この問題を評価できない。

指摘後に実際の生成PNGを開いて確認した。「灯影」のカードは蝋燭、燭台、巻き模様を持ち、古典的な装飾紙を連想させる。「石径」のフレームは立体的な石・結晶・苔の輪で、カードは小石を並べた紙の意匠を持つ。いずれも、色を寄せるだけでは時間・薄明・予定と実績のあいだという既存の世界観とのつながりが明瞭にならない。

## 1. プロフィール — 役割の優先順位に懸念

![プロフィール](01-profile.png)

名前・アイコン・編集と共有の導線は分かりやすい。一方、レベル、ストリーク、XP、友達人数、コレクション、かけらがデイリーカードより先に表示される。「自分の記録が蓄積する場所」より報酬システムの説明が主役になりやすい。友達0人の初期状態でも装飾と友達人数が目立つ。

この初期装備の色差を、生成装飾の世界観が合わない根拠とした前回の評価は撤回する。生成意匠の評価には、上記の蝋燭・石など実際の生成画像を使う必要がある。実寸で名前・記録・操作を読み取りやすいことは、それとは別の品質条件。

## 2. コレクションのカード一覧 — 分類は明確、目的との距離がある

![カード一覧](02-collection-cards.png)

バッジ・フレーム・連続・カード・テーマの5分類と、レベルアップでもらうかけら、解放状態を提示する。興味がある人の任意の遊びとして成立する余地はあるが、日常的なカレンダー利用から得られる価値を説明するには、理解すべき概念が多い。

ロック中のプレビューは薄く、装飾の違いを見比べにくい。小さな補足文字や淡い表示の読みやすさには懸念がある。コントラスト比、読み上げ、大きい文字の検証はしていないため、適合性の判定ではない。

## 3. カレンダー — 装飾との分離は保たれている

![カレンダー](03-calendar.png)

撮影した月表示は日付と予定が中心で、装飾の交換・装着・受取を要求するUIはない。この分離は維持したい。予定が少ない状態のため、密な実データでの認知負荷や現在進行中のカレンダー改修の評価には使えない。

## 判断と次の検討

収集要素を残す余地はあるが、プロフィール装飾をカレンダー利用の中心的な継続報酬にする設計は再検討したい。一人でも自分好みに整える価値はある。ただし、装飾に興味がない人にまで役割を広げる根拠は弱い。

代案は、既存のデイリーカードや月ごとの記録など、自分が過ごした時間が残る収集対象。新しい通貨や受取作業を増やす方式は、それ自体が認知負荷になり得る。プロフィール外への移動やこの代案の採用は未決定。

基本体験を守る条件は、装飾を無視しても予定・記録・振り返りが完結すること、カレンダーの情報表現を変えないこと、獲得で作業を遮らないこと、画像読み込みがタブ切り替え・スクロール・予定操作を遅らせないこと。最後の条件は採用前に実機で測る必要があり、今回の撮影から速度低下の有無は判断できない。

次に比較するのは「任意のプロフィール装飾」と「記録が残る収集」の一人利用時の価値。画像の量産より、この役割を先に整理する。
