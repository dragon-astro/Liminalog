# タイムラインの直接操作と予定編集の整理

2026-09-17。メイン予定を一本の軸とし、その上に独立した予定メモを重ねる仕様（[33](33-plan-memos.md)）の操作を改善する。

## タイムライン

- 日表示・月表示から拡大したタイムライン・週間表示で共通。未選択の予定を長押しすると、押した時刻から予定メモを追加する。長押しした時刻を固定し、指を離さず上へ引けば開始時刻、下へ引けば終了時刻を伸ばす。空き時間でのメイン作成と同じ範囲計算を使い、メモだけ重複の制限を外す。離すまで下書きとして表示し、終了時に一度だけ保存する。新しいメモを選択した状態にし、続けて移動・伸縮できる。
- 長押し作成中はメイン・メモとも最小時間を強制せず、ゼロ長から上下へ伸ばす。ラベルが下書きを押し広げないよう固定枠内に収め、時刻は枠外の共通ガイドでも示す。指を離した時だけ最小時間単位を確保し、保存済みの予定に合わせて時間軸の最小表示高を適用する。
- 空き時間の長押しは成立後に親のスクロール／シートパンと同時認識しない。成立前に動かす通常のスクロールと、ピンチによる操作取消は維持する。
- プリセットもドラッグ中に左でメイン、右でメモへ切り替え、週間では置き先の曜日内の左右を使う。中央帯では直前の種類を保持する。固定時刻のタップ追加は維持し、長押し配置では元の時刻を保つ。長さ指定は置いた位置の時刻を使う。元のプリセットの種類は変更しない。
- タップして選択した予定は従来どおり移動・伸縮できる。選択中の長押しは削除確認。
- 移動中に指を左へ持っていくとメイン、右へ持っていくとメモ。週間では各日付の列の左右で判定する。左右へ動かした意図がない縦移動では種類を保持する。中央には切り替わりの振動を防ぐ余白を設ける。
- ドラッグ中だけ左右のガイドを出し、カードの見た目も切り替える。種類を変更するプレビューは他の予定を押し出さない。メモを左へ移すと、左端からメイン幅で重ねて表示し、下の予定を薄く透かす。他のメインを左右の列に分けない。
- 重なるメインがある場所へメモを移す場合は、プリセットと共通の「現在／時間だけ／予定ごと」の比較で、重なる時間だけの置換（前後を残す）か予定ごとの置換を選ぶ。実際の予定の色・名前・時間を共通の時間軸で示す。初期値は時間だけの置換。「メモに残す」は撤去し、取消時は位置も種類も保存しない。保存直前に対象のリビジョンを再検証し、すべての変更を一括保存する。
- ドラッグの対象IDは操作開始から終了まで固定する。他の予定や空き部分を別の指で触っても選択を変えず、元の対象の種類と時刻で保存／置換確認を判断する。
- 週間の移動はドラッグ開始時の区間を保持する。表示更新で変わった下書き時刻へ累積移動量を再加算しない。
- 今日以前のメインの変更制限、外部カレンダー予定の編集制限は既存どおり。追加したメモの変更は独立して扱う。

## 編集画面

名前、時間、メイン／メモ、カテゴリの順に配置する。重要な予定は名前カード内の星ボタンで切り替える。終日の切り替えを時間カードにまとめる。種類のアイコン・図・説明は撤去し、文字のセグメントだけで選ぶ。通知・繰り返しの現在値は見える位置に置き、公開範囲と文章メモも直接表示する。「その他の設定」の開閉欄は撤去。予定プリセットの編集も同じ方針にする。

短い予定メモもメインと同じ最小表示高に必要な時間軸の拡張対象とする（日・月拡大・週・一日プリセット）。データ上の時間は変えず、同時刻のカードと目盛りを共通の軸に保つ。ドラッグ中の役割ガイドは文字のみとし、予定メモの識別アイコンは取り除く。

## 通知

- 既存の開始時刻／5・10・15・30分／1時間前を維持。2・3・6・12時間、1・2日、1・2・4週間前を追加。
- 実際の予定は「日時を指定…」で任意の通知日時を保存できる。予定を移動しても固定日時を維持する。1予定あたり1通知。
- 日付を持たないプリセットでは相対時間を設定する。任意日時のある予定をプリセット化・繰り返し登録すると、開始時刻との差を相対時間に変換する。以後の各回に元の日付をコピーしない。
- `PlanBlock.reminderDate` は任意属性を追加。旧データではnil。通知の近い順に予約する既存の上限、権限確認、通知タップのカレンダー遷移を維持する。

## 繰り返し

- 毎日・毎週・毎月・毎年。間隔1は「毎日」などと表示し、2以上だけ「2週間ごと」等の間隔を表示する。
- 終了は「しない」「日時」「回数」のいずれか。回数は開始日からの適用日数で、一日プリセットも1日を1回と数える。個別編集・削除・重複で適用できなかった日も回数に含める。
- 月末31日や2月29日など存在しない日はスキップし、回数には含めない。
- 終了日時と同時刻までに始まる予定を対象にする。一日プリセットの最終日は終了日時より後に始まる項目を生成しない。
- 既存JSONの終了日は従来どおり終日を含む。新しく終了日時を選んだ場合だけ厳密な時刻を適用する。
- 設定済みの周期は短い要約へ折りたたむ。長い説明は情報ボタンに収納し、iPhoneでもシート化しない標準の吹き出しで表示する。繰り返し全体／開始日と日付／終了条件／元の設定の変更へ説明を分散する。周期の元を変更しても、各日で調整・削除した予定を作り直さない。
