# 09. プロフィール画面 情報設計 v2

ユーザー設計セッション 2026-05-28 にて、初版（5/26）の前提を改訂。
プロフィールが持つ **二面性**（他人ビュー / 自分ビュー）と、解放要素を **装飾アイテム経済** として再設計する方針を確定した。

このドキュメントは [05-screen-flow.md](05-screen-flow.md) のプロフィール部分を上書きする。

---

## 0. 結論

プロフィール画面は **2つの目的** を同時に担う。

| 目的 | 対象 | 役割 |
|---|---|---|
| A. 他人に見せる自己表現 | 友達ビュー | 公開された自分の活動・装着アイテムの表現 |
| B. 自分のアプリ活動の総覧 | 自分ビュー | コレクション管理・モチベ装置・装着切替 |

同じレイアウトを共有しつつ、**自分ビューだけに表示される要素**を持つ。
他人ビューでは公開フィルタを適用し、自分専用要素は出さない。

統計詳細は **統計タブ** の役割。プロフィールには置かない。

---

## 1. 設計原則

### 1.1 二面性（自分ビュー / 他人ビュー）

- **自分ビュー**: プロフィール = 自己表現 + 自分用ハブ（コレクション・モチベ）
- **他人ビュー**: プロフィール = 公開された自己表現のみ
- 実装は単一 `ProfileView` を `viewMode: .own / .friend(User)` で分岐する

### 1.2 解放要素は「装着可能な装飾アイテム」として実装する

**最重要原則:**
- 「解放しただけ」のアイテムは作らない
- 解放後に **装着して見た目が変わる** ものだけを設計対象にする
- ユーザーが「これが欲しい」と能動的に思える内容であること
- 解放そのものを目的にせず、**欲しいと思うものを作る**

### 1.3 コレクション全体は自分ビュー専用

- 「未解放を含むコレクション一覧」は他人に見せない
- 他人には **装着されたアイテムだけが伝わる**（装着先のプロフィール画像枠・名前バッジ等を通じて）
- これにより「コレクションを誇示する」設計を排除し、解放動機を**装着の楽しみ**に寄せる

### 1.4 統計データはプロフィールに置かない

- カテゴリ別グラフ・ヒートマップ・先週比などは **統計タブ** に隔離
- プロフィールに置く数字は **アイデンティティとして自慢になる蓄積数字** のみ（ストリーク・累計・友達数）

### 1.5 設定は ☰ ハンバーガーに隔離

設定・管理・アプリ情報はプロフィール本体に出さず、右上のハンバーガーメニュー（自分ビューのみ表示）に集約する。

## 2. UIの参照モデル

具体的な配置・装飾・アニメーションは規定しない。以下のSNSのプロフィールパターンを参照すること。

| 参照元 | 学ぶポイント |
|---|---|
| Instagram | 2ゾーン構造（ヘッダー + 投稿グリッド）、☰隔離パターン、ストーリーハイライト |
| X (Twitter) | カバー画像 + 主要スタッツ、bio の扱い |
| BeReal | カレンダー型グリッド、過去蓄積の見せ方 |
| Discord (Nitro) | プロフィール装飾アイテム（バッジ・アバター枠・テーマ）の装着 UI |
| LINE | スタンプ/装着アイテム経済の参考 |

**実装者が新しいUIを発見した場合は本書に縛られず採用してよい。** 情報要素を満たし、設計原則に反しない限り自由。

## 3. 情報要素

### 3.1 両ビュー共通（公開・装着済み要素）

両方のビューで表示される要素。装着アイテムの効果はここに反映される。

#### プロフィール画像（+ 装着フレーム）
- **意図**: 自己同定
- ユーザーがフォトライブラリから設定する画像
- 未設定時はニックネーム頭文字 + 背景色フォールバック
- **装着中のフレーム**（解放アイテム）があれば、画像の周りに表示

#### ニックネーム（+ 装着バッジ）
- **意図**: 自己同定
- 設定可能
- **装着中のネームバッジ**（「夜型」「100日継続」等）があれば名前の横に表示

#### bio
- **意図**: 自己定義
- 1〜2行の自由記述。任意

#### 主要スタッツ
- **意図**: 蓄積と継続の証
- 表示する数字（並び順は実装裁量）:

| スタッツ | 意図 | 装着で変わる要素 |
|---|---|---|
| 🔥 ストリーク | 継続中の状態（loss aversion 装置） | **装着炎バリエーション**（通常炎/青炎/虹炎等） |
| ⏱ 累計記録時間 | 長期投資の蓄積 | 単純数字 |
| 👥 友達数 | 横のつながりの広さ | 単純数字（Phase 3 以降で意味を持つ） |

#### 公開された日記カード（オプション）
- **意図**: 物語の蓄積
- DayDigest アーカイブを表示する場合、**公開設定でフィルタ**された日のカードだけが他人に見える
- 自分ビューでは全件、他人ビューでは公開分のみ

### 3.2 自分ビュー専用要素

他人ビューでは表示されない、自分専用のハブ機能。

#### ☰ ハンバーガーメニュー
- 設定・管理・アプリ情報への入口（§6 参照）

#### プロフィール編集ボタン
- 自分のプロフィール画像・名前・bio・テーマ色を編集

#### コレクションハブ
- 全装飾アイテムの総覧（§4 参照）
- 解放済みは通常表示、未解放はグレーアウト
- ここから装着切替を行う

#### 次に狙う解放（推奨）
- 未解放アイテムのうち、達成に近いものを上位表示
- 例: 「あと3日連続で『青炎』が解放」「あと2時間で『100時間バッジ』」
- 行動への変換を促す装置

### 3.3 他人ビュー専用要素

自分ビューでは表示されないが、他人ビューで追加される要素。

#### アクションボタン行
- リアクション送信
- ミュート / 通報 / フォロー解除 等

## 4. 装飾アイテム経済（解放要素）

プロフィール画面の**継続動機の核**。

### 4.1 アイテムの種類

| 種類 | 例 | 装着箇所 | 他人にも見える？ |
|---|---|---|---|
| プロフィール画像フレーム | 金枠・ホロ枠・季節枠 | プロフィール画像周り | ✅ |
| 名前バッジ | 「夜型」「100日継続」「読書家」 | 名前の横 | ✅ |
| ストリーク炎バリエーション | 通常炎/青炎/虹炎/ハート | ストリーク表示 | ✅ |
| カテゴリアイコンセット | ミニマル/水彩/ピクセル | アプリ全体のカテゴリ表示 | △（公開された日記カード経由で間接的に） |
| テーマカラー拡張 | 標準プリセット8色 → 解放で追加 | アプリ全体 + プロフィールアクセント | △（アクセント色は他人にも） |
| 24時間バーのスタイル | バー/グラデ/水彩 | タイムライン画面 | ❌（自分のみ） |
| 日記カードのテンプレート | スタイル違い | 日記カード | ✅（公開カード経由） |
| 月アートのスタイル | 花/星座/波/万華鏡 | 月アート（実装後） | ✅（公開時） |

### 4.2 解放条件

以下のような **行動の結果として** 解放される。

- 累計記録時間（10時間 / 100時間 / 1000時間）
- ストリーク継続日数
- 連続記録（7日 / 30日 / 100日 / 1年）
- 特定パターン達成（朝5時前の記録 = 朝活バッジ、深夜2時以降 = 夜型バッジ）
- カテゴリ種類数達成
- 季節 / イベント限定（春分の日にログインで「桜枠」等）

詳細な解放スケジュールは別途 `docs/10-unlock-system.md` で扱う（Phase 2）。

### 4.3 装着 UX

- アイテム1種類ごとに1つ装着可能（フレーム1個、バッジ1個 等）
- 装着切替はコレクションハブから
- 装着していないアイテムは自分用コレクションで控えめ表示
- 装着しているアイテムだけがプロフィール本体に出る = **他人にもそれが伝わる**

### 4.4 設計の核となる動機論

このアプリの継続動機を支えるのは「**それが欲しい**」という能動的欲求。
「解放したい」ではなく「**装着したい**」が原動力になるよう設計する。

- ❌ 「N個解放した」をコレクション欲で煽る設計
- ❌ 「解放状況を他人に見せる」設計
- ⭕ **見た目が変わる装着アイテム**で「これが欲しい」と思わせる設計
- ⭕ 装着アイテムは他人にも見えるが、それは副次的（主目的は自分のため）

## 5. 配置しないもの

| 要素 | 除外理由 | 行き先 |
|---|---|---|
| カテゴリ別グラフ・ヒートマップ | 「分析」は統計タブの役割 | 統計タブ |
| 先週比・先月比などの率系 | 内向き分析 | 統計タブ |
| 365日マップ | 月間/年間ヒートマップと役割重複 | 統計タブ |
| 設定項目 | 雑多な情報を本体に出さない | ☰ ハンバーガー |
| カテゴリ管理 | 同上 | ☰ ハンバーガー |
| データ管理 | 同上 | ☰ ハンバーガー |
| **アプリ機能へのナビゲーションリンク** | 各タブから直接行ける | 各タブ |
| **未装着の解放アイテム他人公開** | 他人にコレクションを誇示する設計を排除 | 自分ビューのみ |

## 6. ハンバーガーメニュー（☰）

プロフィール本体から隔離した設定・管理項目はここに集約する（**自分ビューのみ表示**）。

カテゴリ別にセクション分けする。具体的な階層・順序は実装裁量。

- **設定**: 通知 / 公開設定 / テーマ・外観 / アカウント
- **管理**: カテゴリ管理 / カテゴリセット管理 / データのインポート・エクスポート
- **アプリ情報**: バージョン / ヘルプ・FAQ / プライバシーポリシー / 利用規約
- **アカウント操作**: ログアウト など

「**毎日触らない**」項目は全部ここに入れる。

## 7. 自分ビュー / 他人ビューの実装差分

単一 `ProfileView(viewMode: .own / .friend(User))` で実装する。

| 要素 | 自分ビュー | 友達ビュー |
|---|---|---|
| プロフィール画像（+装着フレーム） | ✅ 編集可 | ✅ 表示のみ |
| ニックネーム（+装着バッジ） | ✅ 編集可 | ✅ 表示のみ |
| bio | ✅ 編集可 | ✅ 表示のみ |
| 主要スタッツ（+装着炎反映） | ✅ | ✅ |
| 公開日記カード | ✅ 全件 | ✅ 公開分のみ |
| ☰ ハンバーガー | ✅ | ❌ |
| プロフィール編集ボタン | ✅ | ❌ |
| アクションボタン（リアクション・ミュート等） | ❌ | ✅ |
| **コレクションハブ** | ✅ | ❌ |
| **次に狙う解放** | ✅ | ❌ |

公開設定の粒度（日記カード単位 / 月単位 / カテゴリ単位）は Phase 3 で詳細設計する。

## 8. 実装上の自由度

### 8.1 規定する範囲

本書が **規定する** のは以下のみ。

- どんな情報要素を含めるか
- 各要素の意図（なぜそこにあるか）
- 自分ビュー / 他人ビューの差分
- 装飾アイテムの「装着可能」原則
- コレクション全体は自分ビュー専用の原則
- 統計データを置かない・☰ 隔離の原則

### 8.2 規定しない範囲

以下は実装側が自由に最適化してよい。

- 要素の配置・順序・サイズ・色・装飾
- アニメーション・トランジション
- 視覚的なグルーピング方法
- 「コレクションハブ」「次に狙う」などの UI 文言と表示形式
- 新規ビジュアル要素の追加（設計原則に反しない限り）
- 装着切替UIの具体形（モーダル/インライン/長押し等）

実装者が試行錯誤の中で本書より良い設計を発見した場合は、PR と共に本書の更新提案を行うこと。

## 9. テスト観点

- 他人ビューで **コレクション一覧** が表示されないこと
- 他人ビューで **未装着の解放アイテム** が一切露出しないこと
- 装着切替が **両ビューに即時反映** されること
- 装着アイテムが **公開フィルタの影響を受けない**（装着 = 公開と同義として扱う）
- 解放条件達成時の状態遷移: 未解放 → 解放 → 未装着 → 装着
- 「次に狙う解放」の並び順（達成までの近さでソート）
- プロフィール画像未設定時にニックネーム頭文字フォールバックが出る
- 日記が0件・解放アイテム0件でもプロフィールが破綻しないこと
- ☰ から全ての設定項目に到達できること
- 自分ビューに編集ボタンがあり、他人ビューには無いこと

## 10. Claude/Codex への注意

### 設計判断時

- **「解放しただけのアイテム」を作らない。** 必ず「装着して何が変わるか」を明示する。装着先のない解放アイテムは設計しない
- **「他人に解放状況を見せる」設計を作らない。** コレクション一覧は自分専用。他人ビューに漏らさない
- **装着アイテムは他人にも見える。** これは副次的な効果であり、プライバシー設定の対象にしない（装着 = 公開と同義）
- 新しい要素を本体に追加するときは、まず「**1行で言える意図**」を書けるか確認する。書けない場合は追加しない
- 装飾アイテムを追加するときは、「**ユーザーが能動的に欲しいと思える内容か**」を最初に問う

### 実装時

- 単一 `ProfileView(viewMode:)` で自分/友達ビューを実装する。別画面を作らない
- インスタ・X・BeReal・Discord のプロフィール慣習を参照する。発明する前に既存パターンを確認する
- プロフィール本体に統計データを追加しない（統計タブの役割）
- プロフィール本体にアプリ機能へのナビゲーションリンクを追加しない（各タブから直接到達できる）
- 設定項目はすべて ☰ に隔離する
- 装着アイテムの効果は **両ビューに反映される**（自分にも他人にも）

### 旧版（v1）からの主な変更点

- プロフィールの目的を「他人に見せる自己表現」から「**他人ビュー + 自分専用ハブの二面性**」に拡張
- コレクションを「友達に見せる達成可視化」から「**自分専用のモチベ装置**」に再定義
- 解放要素を「ショーケース」から「**装着可能な装飾アイテム経済**」に再設計
- 装飾アイテムの具体カテゴリ（フレーム・バッジ・炎・アイコンセット・テーマ等）を §4.1 に列挙
