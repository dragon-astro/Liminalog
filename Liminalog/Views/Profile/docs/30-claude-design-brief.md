# Liminalog デザインブリーフ

あなたには、iOSアプリ「Liminalog（リミナログ）」と、その紹介LP（Web）のデザインを作ってほしい。このアプリはすでに動いていて、世界観と配色の設計が固まっている。**ゼロから発明するのではなく、下記の世界観を正確に体現するビジュアルを作ってほしい。**

## 1. 製品の本質（これが全て）

Liminalog は、**「朝に立てた予定」と「実際に過ごした実績」を、ひとつの24時間に重ねて記録する**アプリ。記録するのは予定でも実績でもなく、その**「あいだ（＝ズレ）」**。予定どおりに動けた日はきれいに重なり、ズレた日は静かに分かれる。**どちらも責めず、ただ美しく残す。** 一日の終わりには、その日の過ごし方から「今日の称号」が決まった一枚のカードが届く。

## 2. ターゲットユーザー

Z世代〜20代中心。几帳面な自己管理が続かない人。「今日なにしてたっけ？」が口ぐせ。生産性アプリの説教くささ・意識高さが苦手。エモい・空気感のあるもの、シェアして映えるものが好き。**「毎日を予定どおりに生きられる人には、たぶん要らないアプリ」** というくらいの温度感。

## 3. 世界観：liminal（境界・あいだ）× twilight（薄明かり）

- **liminal ＝ 境界・あいだ。** 誰もいない廊下、午前4時、夢の途中。Z世代が知っている「リミナルスペース」の郷愁とざわつき。生産性アプリは絶対にここに居ない＝**最大の差別化**。
- 美学は **トワイライト（夜明け／黄昏）＋ ダークファースト ＋ 空気感（微グラデ・柔らかい発光・フィルムグレイン）**。青い生産性アプリから離れ、静かでエモい場所にする。
- **隠れた核ストーリー：「黄昏（たそがれ）」の語源は「誰そ彼（たそかれ）＝"あれは誰？"」。** 夕暮れは暗くて人の顔が見分けられない＝境界（liminal）の時間。アプリの世界観が日本語の単語そのものに埋まっている。テーマ名は古風な薄明かり語（宵・曙・黄昏・茜・朧・群青…）で統一する。
- 判断に迷ったら基準はひとつ：**「これは twilight／liminal の空気か？ 生産性ツールっぽくないか？」**

## 4. トーン＆ボイス（ビジュアルは静謐、コピーは自虐）

- ビジュアルは**静かで美しい**。コピーは**ちょっと自虐で、あたたかい**。この対比がZ世代に効く。
- 「目標を粉砕」ではなく「今日を受け取る」。説教しない、命令しない。
- 実際のアプリ内コピー例（この温度を守ること）：
  - 称号「有言実行の人」→「過去の自分が立てた予定どおりに、今日の自分がちゃんと動けた。えらい、これはもう事件です。」
  - 称号「昼の集中砲」→「2時間30分ぶっ通しで仕事。集中力の在庫、たぶん今日で使い切った。」
  - プロフィールひとこと「課題が終わらねぇ…」／ペルソナ「深夜稼働型」

## 5. アプリの情報設計（5タブ構成）

下タブは5つ：**ホーム / カレンダー / 統計 / 友達 / プロフィール**。

- **ホーム（今日）**：昨日・今日・明日を切り替え。今日＝カテゴリを選んで記録開始＋予定/実績の24hバー＋実績リスト。昨日＝その日のデイリーカード（後述）。
- **カレンダー**：月グリッド。各セルは数字の羅列ではなく、**「ミニ二重リング」や濃淡**で良い日/悪い日のリズムを俯瞰できる（正確なスコアは日詳細で）。
- **統計**：週/月/年。主役は**トレンド（続けて自分が変わっているか）**。スコア推移・カテゴリ推移。単発の内訳は控えめ。
- **友達**：相互承認した友達と共有。主役は**今のステータス＋ひとこと**。ランキング（競争）は従・控えめ。
- **プロフィール**：装飾されたプロフィールカード、レベル、ストリーク、継続XP（＝成績でなく「続けた長さ＝献身」）、コレクション（称号＋解放テーマ）、デイリーカード履歴。

## 6. signature：二重24時間リング（製品の顔）

**この図形がブランド。必ず主役として使う。**

- **円1周＝24時間。** 0:00 が真上（12時位置）、時計回り（朝＝右、正午＝下、夕＝左、深夜＝真上に戻る）。
- **二重の同心リング：内側＝予定（Plan）／外側＝実績（Actual）。** 各弧セグメントは、色＝カテゴリ色、角度位置＝時刻、弧長＝継続時間。
- **内と外が同角度で違う色＝ズレ。揃う＝調和。この差分こそが liminal の主役。**
- 未記録・未予定の時間＝**淡いゴースト弧**（主張しない、埋めたくなる余白）。
- リング外周に twilight の柔らかい glow。中央は基本余白、置くならスコア数字を控えめに。
- カレンダーのセルには、この「ミニ二重リング（簡略版）」を展開してもよい（世界観的で美しい）。

## 7. カラーシステム（twilight の空・純黒/純白を使わない）

色を**意味（トークン）**で扱う：canvas / surface / elevated / divider / text / secondary / tertiary / primary / reward ＋ グラデ3点。テーマを変える＝このパレット一式を差し替える。

### デフォルト・ダーク＝「宵（Dusk）」
| 役割 | hex |
|---|---|
| canvas | `#0D0B16` |
| surface | `#17132A` |
| elevated | `#1F1A38` |
| divider | `#2A2442` |
| text / secondary / tertiary | `#ECE8F5` / `#9A93B5` / `#6E6890` |
| primary（主役・操作・ブランド） | `#C9A7FF`（発光する薄紫） |
| reward（特別・ご褒美） | `#FFE3A3`（暖かい金） |
| dawnグラデ例 | `#FFB3C7` → `#C4A5E8` → `#FFE3A3` |

### デフォルト・ライト＝「曙（Daybreak）」※純白禁止・設計された夜明け
| 役割 | hex |
|---|---|
| canvas | `#F4EEF6`（ラベンダー寄りオフホワイト） |
| surface / elevated | `#FBF6FB` / `#FEFAFE` |
| divider | `#E6DCEC` |
| text / secondary / tertiary | `#2A2440` / `#6A6388` / `#9A93B5` |
| primary | `#7C4DD6`（ライト地で映える濃い菫） |
| reward | `#C98A1E`（濃い琥珀） |
| dawnグラデ | `#FFE3EC` → `#EBDCFA` → `#FFF0CE` |

> ライトはシステム白に丸投げしない。**設計された dawn**（「春はあけぼの」）。primary/reward はライトでは濃く（コントラストが逆向き）。

### 解放テーマ（世界観の変奏・任意色は作らない）
すべて「別の薄明かりの空」。ネオン等の世界観破壊色は禁止。例：
- **黄昏（Twilight）** 茜と紫が溶ける境界＝象徴テーマ。canvas `#160B16` / primary `#E89ACB` / グラデ `#3A1530`→`#6B2F55`→`#C9683E`
- **茜（Crimson）** 夕焼けの紅。canvas `#170A0E` / primary `#FF8FA3` / グラデ `#4A1320`→`#8C2A30`→`#E0743C`
- **群青（Ultramarine）** 深い真夜中の青。canvas `#08101F` / primary `#7FB0FF` / グラデ `#0A1A3A`→`#1E3A6E`→`#3A6BB0`
- **朧（Haze）** 霞んだ銀ラベンダー・朧月。canvas `#12121C` / primary `#BFC4E8` / グラデ `#2A2C40`→`#4A4C68`→`#8A86A8`

### 色の運用ルール（優先度を生む・厳守）
1. **色は希少資源。** UIの大半は中立（テキスト/面）。全部光ると主役が消える。
2. **1画面に primary（紫）は"一番大事な1要素"だけ**（主CTA・選択中タブ等）。
3. **reward（金）はさらに希少**。スコア・達成の瞬間だけ。
4. **カテゴリ色は"データ層"だけ**（リング/バー/タイムライン/カテゴリピル限定）。**ボタン・ナビ・chrome には絶対に使わない。** ← chrome色（紫/金/中立）と data色（カテゴリ）の分離が、優先度を読める画面を作る最大の処方。
5. **視認性 > 世界観（絶対）。** データや文字が読めなくなる配色は却下。

## 8. タイポグラフィ

- **Display（称号・カードのヒーロー文字・見出し）**：個性のある書体で大胆に、余白たっぷり、editorial。和文は字面の強いゴシック or 明朝系で「静かな品」を出してもよい。
- **Body（本文）**：読みやすい標準ゴシック。静かに。
- **Numeric（スコア・時間）**：tabular/等幅寄りで「データの精度」を感じさせる（ただし冷たくしない）。
- 肝心なところだけ大胆、他は静か。

## 9. 空気感（"魂"・抑制が命）

- **フィルムグレイン**：全面に低不透明度（3〜5%）のノイズ。デジタルの平坦感を消す。
- **ソフト発光（glow）**：リングやヒーロー要素の背後に twilight アクセントの柔らかい放射状グロー（大きめblur）。
- **グラデ面**：主要な面はベタ塗りでなく微グラデ（dawn/dusk）。
- ルール：グレイン ≤5%、glow は柔らかく、**同時に主張する要素は1つ**。うるさくしない（liminal は静けさ）。

## 10. モーション

- 穏やかな easing。全所バウンドspringは避ける（静けさと喧嘩する）。
- 鍵となる瞬間だけ演出：リングが時計回りに**描かれていく**、称号のreveal、カード出現。
- soft fade / gentle slide。

## 11. アンチパターン（これをやったら世界観が死ぬ・禁止）

- ❌ 純白背景・純黒・臨床的な生産性アプリの見た目
- ❌ iOSデフォルト青アクセント・system既定のchromeそのまま
- ❌ flat material・空気感ゼロ（グレイン/グラデ/glowなし）
- ❌ 多色アクセントが乱立してうるさい
- ❌ 量産の実績バッジ的ゲーミフィケーション
- ❌ 過度に可愛い or 過度に企業的
- ❌ カテゴリ色を chrome（ボタン/ナビ/タブ）に使う
- ❌ primary紫を1画面で複数の主役に乱用（優先度が消える）
- ❌ スコアをあちこちに出しすぎる（希少性が死ぬ）

## 12. デザインしてほしいもの（優先度つき）

**A. まず：デザイン言語／ムードボード（1枚）**
上記の世界観を体現する、色・質感・タイポ・glow・グレイン・二重リングの見え方を1枚に。宵（ダーク）と曙（ライト）の両方。

**B. LP（Web・日本語・ダークファースト・モバイルファースト）**
- ヒーロー（二重リングを主役に／「近日公開」バッジ）→ コンセプト（予定と実績のあいだ）→ 使い方3ステップ（朝・日中・夜）→ デイリーカード（シェアの顔）→ 続けたくなる理由（統計・装飾・友達）→ クロージング（夜明けのグラデで締める）。
- 静謐×自虐のコピー。装飾過多にしない。

**C. アプリUIの方向性（主要画面のビジュアル探索）**
- **デイリーカード**（最重要・シェアされる顔／9:16）：二重リング＋称号（大）＋自虐の説明＋パンチ事実＋スコア。生スクショでなく「貼りたくなる designed な一枚」。
- ホーム（今日）／カレンダー（ミニリングのセル）／統計（トレンド主役）／プロフィール（装飾カード）。
- ダーク（宵）とライト（曙）両方で同品質・同視認性。

## 13. 制約

- 日本語。ダークファースト、ただしライト（曙）も必ず設計する（手抜きの白は禁止）。
- モバイルファースト（スマホでシェアされる前提）。
- ブランドは**形（二重リング／レイアウト／Liminalogマーク）で担保**するので、テーマで色が変わっても認識できること。
