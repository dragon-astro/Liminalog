# 33. メイン予定と予定メモ

2026-09-17 ユーザー決定・試用実装。計画と達成度は一本のメイン時間軸を維持し、カレンダー用の時間付きメモを独立したレイヤーで重ねる。メモを同時実績や追加の達成条件として扱わない。

## 操作

- 予定編集の名前・時間の下に「メイン予定 / 予定メモ」のセグメントを置く。時刻・名前・カテゴリ・通知を保って種類を変更する。予定プリセットと一日プリセット内の予定編集にも同じ選択を設ける。
- メイン→メモは通常の保存で切り替える。メモ→メインに重複がなければ同じ操作で戻せる。
- メモ→メインで他のメインと重なる場合は、小さなシートに実際の名前・色・時刻を表示して確認する。プリセットと共通の3列（現在／時間だけ／予定ごと）で、重なる時間だけの置換と予定ごとの置換を比較して選ぶ。初期値は時間だけの置換。「メモに残す」は置かず、取消で元のメモの位置・種類を保つ。詳細は[34](34-timeline-direct-edit-and-scheduling.md)。
- 確認は相手のID・更新日時・時刻等を値として保持し、保存時に再照合する。外部所有の予定や変更不可のメインが対象なら切り替えない。
- メモ同士、メモとメインは自由に重ねられる。移動・伸縮で他の予定を押し出さず、メインを動かしてもメモは追従しない。
- 今日・過去のメモも追加・編集・移動・削除できる。従来のメイン予定の日付ロックは維持する。今日以前の時間指定メインをメモへ変更すること、メモを今日以前の時間指定メインへ変更することはロックの対象。docs/27のロック緩和は別件。

## 表示

日タイムライン・月間から拡大したタイムライン・一日プリセットの編集では、メインのカード幅を保ち、右側48%に予定メモを重ねる。週間は右側50%。メモには背景色とカテゴリ色の枠線を使い、塗りのメインと区別する。メモ同士の重複だけで列を分け、メインの列レイアウトは変えない。短いメモもメインと同じ最小表示高を確保するよう共通の時間軸を広げ、時刻と表示位置を揃える。メイン選択中もメモを前面に残す。短いメモでは名前を優先する。

週間の幅24pt未満のメモは名前の先頭文字で表示し、タップで選択、再タップで内容を編集する。週間カードのタップを外側のカード範囲にまとめ、メモを押した際に背面のメインが開く問題を実機で修正・確認した。

月間の当日一覧では時刻の前に「予定メモ」を表示する。プリセットのタイルにも種類を表示する。従来の下余白からの右スワイプと、プリセットボタンを含めた一覧への遷移を維持する。

## 保存・評価

- `PlanBlock` / `PlanPreset` に既定値falseの `isMemo` を追加。既存予定はメインのまま。
- `PlanTemplateSnapshot` / 繰り返しの基準値 / 友達共有のJSONでは、欠落をメインと解釈する任意の値として記録する。既存プリセットのJSON形式のバージョンは変えない。
- プリセット適用・月間の複製/移動・繰り返し生成で種類を保持する。重複・置換の判定はメイン同士だけ。メモは既存の置換で消さない。日ごとの種類変更も繰り返しの個別調整として保持する。
- 達成度、予定時間、空き時間の判定、Homeの現在予定・予定タイムライン・振り返りの予定リングからメモを除外。カレンダーの予定件数と一覧には表示する。
- 過去のメモをスコア履歴の集計開始日にも使わず、メモだけの古い日付まで履歴を走査することを避ける。
- 予定メモの追加・時刻変更・種類変更は通常の更新通知を通す。スコアキャッシュの署名にも種類を含め、切り替え直後の値を取り違えない。
- 共有の種類をJSON・個別レコードに保持し、同じ時間のメモがメインの公開を間引かないようにする。
