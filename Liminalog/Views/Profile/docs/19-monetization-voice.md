# 19. マネタイズの語り口・対外文言ガイド

[17-monetization.md](17-monetization.md) が**戦略（何を有料にするか）**を決める内部仕様なら、本書は**語り口（ユーザーにどう見せ・どう伝えるか）**を決める層。
**設計（docs/17）は一切変えない。** 変えるのは「世間に見せる時の言葉」だけ。

> 大原則：**同じ機能でも、運営目線とユーザー目線で呼び名が逆になることがある。**
> 内部メモ（docs/17）は戦略語のままでいい。**ユーザーの目に触れる場所だけ、優しさの側の言葉に翻訳する。**

---

## 0. 課金の基本姿勢（理念）

Liminalog の課金は、

- **機能を解放するための通行料ではない。**
- **広告を消すための身代金でもない。**
- **この体験をこれからも続けるための「応援」である。**

守りたいこと：「何をしたかわからない一日をなくす」「友達とゆるく繋がる」。
**課金は最初に考えるものではなく、ユーザー体験を守った結果として必要になるもの**として扱う。

- 不便を与えて課金を促すのではなく、**価値を感じた人が自然と支援したくなる形**を目指す。
- 理想は「課金しないと満足に使えない」ではなく **「無料でも十分使える」を前提**にすること。
- 特典（テーマ・カード）は**売り物ではなく、応援へのお礼（返礼品）**として位置づける。
- 課金価値を「画像そのもの」に置かず、**「Liminalog という場所を支えること」**に置く（AIで作ったものを高く売っている、と感じさせない）。
- 運営とユーザーは対立関係ではなく、**一緒にこの場所を育てる関係**。

→ docs/17 の北極星「**苦痛で払わせない。欲しさ（自己表現・見せる価値・深さ・支援）で払わせる**」と同じ思想。本書はその思想を**言葉のレベルでも**守るためのもの。

## 1. 「焦らし」について（重要・認識合わせ）

docs/17 では戦略語として **「じらし（焦らし）」** を使っている（§0/§2/§3/§6/§9）。
だがその**実体は「優しさ」**である：

- §3「統計タブを**24時間解放／7日に1回**」「**代替でなく欲しさを育てる**」
- §6 縛り方の弱い順「数量/期間の余裕枠 → **リワード（じらし）** → ハードロック」＝じらしは**ハードロックより優しい側**

意図は **「完全に締め出す代わりに、時々ちゃんと無料で使わせてあげる」**。
同じ機能を、立場で逆に呼んでいるだけ：

| 立場 | 呼び方 |
|---|---|
| 運営目線（戦略メモ） | 「じらし／焦らし」 |
| ユーザー目線（実体） | 「時々、無料でじっくり使える」＝**お試し解放** |

**結論：**
- **内部仕様書（docs/17）＝「じらし」のままでよい。** 戦略語として正確。
- **ユーザーに見える場所＝「じらし／焦らし」という言葉は出さない。** 優しさの側の言葉で表現する。

## 2. 内部語 → ユーザー向け文言 対応表

| 内部の戦略語（docs/17 等） | ユーザーに見せる言葉 | NGワード（使わない） |
|---|---|---|
| じらし／焦らし | **○日に1回、無料でじっくり見られます** / お試し解放 | じらし、焦らし、限定解放（の煽り） |
| 統計タブ丸ごとロック | 基本の振り返りは無料。**もっと深い分析**を Pro で | 「統計を見たいなら課金」 |
| ハードロック／締め出す | **Pro で使えます** | ロック、制限、使えません（断定） |
| ペイウォール | **応援する / Pro を見る** | 購入を促す煽り文 |
| 課金・購入 | **応援する / 支える / 手に入れる** | 「買ってください」 |
| 特典・返礼品 | **応援のお礼として** | 「特典でお得」 |
| 単品所有 | **お気に入りを永久に持つ** | — |
| レンタル（サブ装着） | **契約中はぜんぶ使い放題** / 再開すれば戻ります | — |
| ARPU・転換率・LTV | （ユーザーには一切出さない・内部のみ） | — |

## 3. コピー原則（ユーザーに触れる文言すべて）

1. **「なぜ」を機能より先に語る。** 新機能紹介より「なぜ作ったか・どんな体験を守りたいか」。課金も「購入してください」ではなく「私たちはこういう場所を作りたい」の延長に置く。
2. **主語は対立でなく共同。** 「一緒にこの場所を育てる」。運営 vs ユーザーの構図を匂わせない。
3. **断定で締め出さない。** 「使えません」ではなく「Pro で使えます」「○日に1回無料で見られます」。閉じる言葉より**開く言葉**。
4. **数字（価格）は脅しに使わない。** 「今だけ」「残りわずか」等の希少性煽りは世界観を壊す → 使わない。
5. **特典は「お礼」の語順。** 「この機能が欲しいから払う」ではなく「応援したいから払う」が先に来るトーン。
6. **静謐を守る（docs/13）。** 搾取的・うるさい接客にしない。WTP最大の瞬間（お気に入りを装着した瞬間など）に、**そっと一度だけ**出す。

## 4. 聖域（語り口でも守る）

docs/17 §6 のガードレールは、文言レベルでも死守：

- **自分の生データを人質にしない** → 過去の閲覧は無料。「過去を見るには課金」的な文言を絶対に作らない。
- **シェア／友達入口は無料**（成長エンジン）。ここに課金導線・煽りを置かない。
- 広告を置かない聖域＝**デイリーカード・ホーム記録・友達タイムライン**。

## 5. 運用

- 本書は **docs/17 と必ずペアで読む**。docs/17＝何を、docs/19＝どう言うか。
- 実装でユーザー向け文字列（ペイウォール・解放告知・チップ訴求）を書く時は、§2 の対応表と §3 原則に通す。
- 矛盾を見つけたら **docs/17 ではなく文言（docs/19 側）を直す** のが原則（設計は据え置き、見せ方で吸収）。
